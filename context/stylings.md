# Styling Specifications

This file provides guidance as to the stylings of the UI.

## Overview
The UI/UX of this application will be handled through Bootstrap's CDN and using V5 of Bootstrap. Custom CSS should be avoided unless not possible to achieve the design requirements of an element using Bootstrap V5. All classname components should follow Bootstrap's naming conventions.

## Colour Scheme

- Background colour: #0f0f18
- Borders and trim colour: #8400ff
- Text heading colour: #ddd
- Main text colour #888
